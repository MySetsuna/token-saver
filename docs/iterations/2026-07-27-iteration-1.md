## 设计取舍

- 没有另造 CLI 或库：沿 `token-usage.mjs` 原入口加完整切片，安装面无需新增二进制。
- 请求级预算证据缺失时 fail closed；普通报告不设 flags，保持兼容。
- 不读取正文，不打印绝对日志路径。
- 不内置价格表；价格随模型/时间变化，成本由用户显式传入。

## Reframe 表

| 原建议 | 可测切片 | 验收 | 判定 |
|---|---|---|---|
| 高 cache hit 即高效 | provider-correct 比例 + 绝对量 + 峰值 | fixture 数学断言 | reframed 采纳 |
| Context Floor watcher | 平均 cache read/request proxy + 请求峰值 | known/unavailable 边界 | reframed 采纳 |
| 自动 compact | opt-in 预算退出码，输出交用户/脚本 | pass/violation/unavailable | reframed 采纳 |
| reasoning 高故质量高 | cost/diff/quality 显式三证 | 缺项 `insufficient` | reframed 采纳 |
| runtime Cache-Lint | 复用离线 cache-lint/prefix-check | 既有 tests | non-goal + 替代 |
| 内置 AST/Rust/语义缓存 | CodeGraph/repomix/外部工具 | 无重依赖 | non-goal + 替代 |

## 熔断

- 首轮测试发现会话记录 spread 顺序使 Codex provider 被内部 `openai` 覆盖；根因一处改为显式 provider 最后写入，复测全绿。
- 无预算/回合上限熔断。
