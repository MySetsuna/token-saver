# iterations/ 命名规范

全部仅本地 git 归档，**不上传 NotebookLM**（唯一上传的是 `docs/PROJECT-STATE.md`）。

| 文件 | 说明 |
|---|---|
| `CONTRACT-iteration-{N}.md` | 第 N 轮合同：目标/边界/可验证验收/停机条件 |
| `{YYYY-MM-DD}-iteration-{N}.md` | 第 N 轮进度报告（历史存档） |
| `{YYYY-MM-DD}-notebooklm-guidance-{N}.md` | 第 N 轮 NotebookLM 原文指导 + 对抗评审 |
| `YYYY-MM-DD-headroom-research.md` | 外部调研归档（本轮 Headroom） |
